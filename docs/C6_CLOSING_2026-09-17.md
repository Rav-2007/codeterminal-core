## A finding this report produced by checking the gate that checks it

The handover list carried a row reading *"`docs-coderefs` counts 19 enforced
documents where 23 carry the marker"* as a **counting disagreement**. It is not one.
It has a mechanism, and the mechanism is a vacuity hole.

In `scripts/docs-coderefs.sh:93` the citation set is tested for emptiness and the
document is skipped — **before** the enforcement marker is looked at in
`scripts/docs-coderefs.sh:95`. So a document that carries the marker but has no
citation matching the pattern is counted in **neither** total. It is not reported as
enforced, not reported as unenforced, and does not appear in the banner at all.

Derived rather than estimated, and the arithmetic closes exactly:

| | |
|---|---|
| Documents carrying the marker | **24** (`git grep -l`) |
| Silently dropped | **5**, listed: `docs/C5_METHOD_2026-09-15.md`, `docs/C5b_TOPOLOGY_2026-09-15.md`, `docs/C7b_DELIVERY_2026-09-16.md`, `docs/CHECKPOINT_ADDENDUM_2026-09-16.md`, **and this report** |
| Reported as enforced | **19** — and 24 − 5 = 19 |

**The counting disagreement was the symptom.** The defect is that a document leaves
the enforced set silently: reformat its citations — drop the backticks, or write a
path without a `:line` suffix — and the gate stops inspecting it while continuing to
pass. The gate does have a vacuity floor, but it is **global** (zero references
checked across all documents is a failure), and a global floor cannot see one document
going dark while others still carry citations. **This is the enumerated-scope failure
in its vacuity form, inside the gate this pass extended twice.**

`(M)` — measured. **Recommended, not implemented**, and deliberately so: a per-document
vacuity floor changes which runs are red, and the closing chunk's job is to land a
merge, not to alter a verdict surface underneath it. Implementing it would also
immediately fail four existing documents and this one, which is H14's situation
exactly — a rule needing five exemptions at birth. The right shape is probably to
report marker-carrying documents with zero citations as a distinct third category
rather than to fail them, and that is a design decision with a measurement attached,
which is to say the next pass's work and not this one's.

**And it applied to this document.** This report carried the marker while being in the
dropped set, so its marker was a claim the gate did not honour. The two citations
above are real, resolve, and put it in the enforced set — which is the smallest
honest fix and also the reason the finding was found at all.
