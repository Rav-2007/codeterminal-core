# Per-module ceilings on UNCHECKED ERRORS outside tests (errcheck -ignoretests).
#
# These are grandfathered counts, not targets. The point is that they may not
# GROW: debt item (j) deferred errcheck adoption for sound reasons, but the
# deferral had no mechanism and the count drifted from 157 to 170 in two weeks.
#
# Lower a number whenever triage removes a site -- the script FAILS on a count
# below its ceiling, so a ratchet that has slackened is reported rather than
# quietly tolerated. Raising one is a decision that belongs in a commit message.
#
# 2026-08-01: daemon 111 -> 108, editapply 12 -> 10. The remediation pass added
# seven new unchecked sites and the ratchet caught every one. Rather than
# grandfather them, each was made explicit -- and so were the pre-existing
# neighbours they sat beside, because half a function using `_ =` and half not
# is worse than either. Net: fewer unchecked errors than before the pass, which
# is the direction these numbers are supposed to move.
#
# 2026-08-02: daemon 108 -> 107. The transport seam gave reclaimStaleSocket a
# second probe branch (a named pipe leaves no filesystem residue, so "stale"
# there means only "nothing answers"), which added one unchecked Close. Rather
# than grandfather it, both probe closes were made explicit with the reason --
# the probe has already answered the only question asked -- so the count went
# down rather than up.
#
# 2026-08-02: editapply 10 -> 9. Splitting applylock.go per platform for the
# Windows port moved the flock release into unlockFile, and the new call is
# explicit where the old inline one was not. The ratchet reported the SLACK
# rather than ignoring it, which is the half of a two-directional ceiling that
# usually goes unappreciated: an unclaimed improvement is how a ceiling drifts
# back up unnoticed later.
#
